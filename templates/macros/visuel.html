{#- Macros chrome pour les figures éditoriales (.visuel--chart). Extrait après la "règle de 3" : V1 METR, V2 Faros, V3 GitClear avaient toutes la même enveloppe (figure / band / title / [legend] / SVG / caption). On garde uniquement le SVG et les données spécifiques dans chaque shortcode `code__v.html` ; la signature visuelle vit ici. Pourquoi deux macros (frame_start / frame_end) plutôt qu'une avec body : Tera 1.x n'a pas de bloc "caller" comme Jinja2. Le pattern start/end laisse le SVG en clair dans le shortcode (lisible, modifiable sans passer par un argument multi-ligne échappé). Usage : {% import "macros/visuel.html" as visuel %} {{ visuel::frame_start( num="V1", tag="Perception ≠ réalité", title_html="Gain de temps perçu
...", pos="side", title_id="v1-title", desc_id="v1-desc" ) }} {{ visuel::frame_end( caption_text_html="...", caption_source_html="..." ) }} Legend (V3 only pour l'instant) : passer `legend_html` à frame_start. -#} {# `variant` (défaut "chart") permet d'utiliser le chrome avec d'autres types de figure (V4 incidents, V6 table, …). Génère `.visuel--{variant}`. #} {% macro frame_start(num, tag, title_html, pos="side", title_id, desc_id, legend_html="", variant="chart") %} {% endmacro frame_end %}
